# Filmory 功能对比：iOS/macOS 原生端 vs Web 网页端

本文档用于对比 **Filmory Swift 原生端** 与 **Filmory Web 网页端 (当前 React SPA 实现)** 的功能对齐情况，帮助评估 Web 端目前的开发进展、已实现及未实现的功能，以便规划接下来的开发任务。

---

## 总体实现状态概览

| 模块 (Module) | iOS/macOS 原生端状态 (Swift) | Web 网页端状态 (React + Dexie) | 关键缺失 / 待对齐功能 |
| :--- | :--- | :--- | :--- |
| **1. 相机管理 (Gear - Cameras)** | ✅ 完整实现 (Phase 3) | ✅ 基础 CRUD 已实现 | ❌ 暂不支持相机头像上传/大图预览<br>❌ 缺少常用镜头推荐 |
| **2. 镜头管理 (Gear - Lenses)** | ✅ 完整实现 (Phase 3) | ✅ 基础 CRUD 已实现 | ⚠️ 网页端仅为参数表格，缺少网格视图和头像占位 |
| **3. 胶卷管理 (Gear - Films)** | ✅ 完整实现 (Phase 3) | 🟡 部分实现 | ❌ **缺少完整的库存管理** (添加库存、持有/已用完)<br>❌ 缺少新建拍摄消耗库存逻辑 |
| **4. 拍摄卷管理 (Rolls)** | ✅ 完整实现 (Phase 3) | 🟡 部分实现 | ❌ **不支持照片拖拽重排序** (Drag & Drop)<br>❌ 缺少自动扣减胶片库存的交互 |
| **5. 照片库 & 时间流 (Photos)** | ✅ 完整实现 (Phase 5) | ✅ 基础功能已对齐 | ⚠️ 网页端采用缩放滑块控制列数，非双指捏合缩放 |
| **6. 照片查看器 (Photo Viewer)** | ✅ 完整实现 (Phase 5) | 🟡 基础查看已实现 | ❌ **缺少 matchedGeometryEffect 展开收起动效**<br>❌ 缺少手势滑动（下拉/斜拉）关闭查看器 |
| **7. 对比工作台 (Compare)** | ✅ 交互升级 (Phase 5) | 🟡 部分实现 | ❌ **缺少横向堆叠 (Rows) 对比模式** (当前仅支持 Side-by-Side 和 Split) |
| **8. 标签管理 (Tags & PhotoTags)** | ✅ 完整实现 (Phase 4) | ❌ **完全未实现** | ❌ 数据库 schema 与 UI 均未实现 Tag 实体及关联 |
| **9. 数据分析 (Stats)** | ✅ 完整实现 (Phase 6) | 🟡 基础图表已实现 | ⚠️ 指标较 iOS 简化 (iOS 有 12 项，Web 目前为 3 张卡片 + 3 个图表) |
| **10. 冲洗记录与器材扩展** | 🟡 规划中 (Phase 5.5) | ❌ **未实现** | ❌ 冲洗 Notepad 与 Other Equipment 扩展均未开始 |

## 详细对比说明

### 1. 相机与镜头管理 (Cameras & Lenses)
* **iOS 已实现**:
  - 相机与镜头的 CRUD 交互。
  - 相机头像/封面图上传，并在列表/详情页进行大图预览。
  - 创建拍摄卷时，根据相机类型（单反、旁轴等）自动推荐常用镜头。
* **Web 已实现**:
  - 纯前端 IndexedDB (Dexie.js) 的相机与镜头 CRUD 逻辑与表单。
  - 胶片/数码双模式的表单切换。
* **Web 缺失**:
  - **图片头像上传**: 网页端相机列表与详情暂不支持上传自定义相机图片，仅有默认图标占位。
  - **智能推荐**: 缺少常用镜头推荐的过滤和提示逻辑。

### 2. 胶卷型号与库存管理 (Film Stocks & Inventory)
* **iOS 已实现**:
  - 胶卷型号 CRUD 与过期/品牌/ISO/色彩多维筛选。
  - **库存扣减系统**: 支持“添加库存” (持有数量) 和“已拍完”状态切换。新建拍摄卷时，若选择某卷胶片，会自动扣减该胶卷的库存。
  - **ArchivedRollQuickAdd**: 胶卷列表支持对拍过的胶卷直接补录已拍完卷，不扣减库存。
* **Web 已实现**:
  - 胶卷型号的 CRUD 列表及基础过滤。
  - 内置 Digital 占位型号并在列表中隐藏的逻辑（对齐 Film Mode Gate）。
* **Web 缺失**:
  - **库存数量跟踪**: Web 端数据库 `filmStocks` 表目前虽有 schema 结构，但 UI 暂不支持库存数量累加、持有与拍完状态的动态流转。
  - **新建拍摄扣减**: 新建 Roll 时没有自动关联并扣减 FilmStock 库存的逻辑。

### 3. 拍摄卷管理 (Rolls Management)
* **iOS 已实现**:
  - 进行中与已归档的双栏结构。
  - 卷详情导入照片（支持相册/Files/拖拽）、多选、删除。
  - **重排序**: 支持在卷详情中通过拖拽修改照片的顺序。
  - 归档默认以照片为主的 Carousel 网格展示。
* **Web 已实现**:
  - 进行中 (active) 与已归档 (archived) 的状态流转。
  - 冲洗备注、价格（胶卷/冲洗费用）记录及地点保存。
  - 卷详情的照片导入与删除。
* **Web 缺失**:
  - **拖拽重排序**: Web 端暂不支持拖拽照片卡片修改排序指数 (`orderIndex`)。
  - **Carousel 展示**: 归档页面仅为常规卡片列表，缺少 iOS 端的横向 Carousel 照片预览组合。

### 4. 照片主页、时间流与查看器 (Photos & Viewer)
* **iOS 已实现**:
  - 纵向时间轴网格，最新照片在底部。
  - **捏合缩放**: 支持双指手势无极缩放列数（2~8列）。
  - **PhotoViewer 沉浸式动效**: 使用 SwiftUI 共享元素过渡 (`matchedGeometryEffect`)，使照片从点击位置顺滑放大，且支持上下或斜向拖动直接手势关闭。
  - EXIF 数据自动读取（GRDB 读取落库）。
* **Web 已实现**:
  - 纵向照片时间流网格，并在顶部导航中提供了 **2~8 列的无极缩放调节控制条**。
  - 模糊搜索、相机/胶卷/评分的多维组合过滤。
  - **纯前端 EXIF 解析**: 依靠 `exifreader` 库在上传时提取焦段、光圈、快门、时间并落库。
  - 初始化时，通过 Canvas 自动绘制测试卡图片填补数据库示例。
* **Web 缺失**:
  - **高级动画交互**: 点击照片打开详情时，网页端是常规的 Modal/弹窗式淡入淡出，**缺少跟随点击位置缩放的弹性物理动效**，且不支持手机端的手势滑动（下拉）关闭。

### 5. 对比工作台 (Compare Workspace)
* **iOS 已实现**:
  - 限制为双对象 (A/B) 联动。
  - 模式顺序：`横向 (Rows)` → `纵向 (Grid)` → `Split (滑尺)`。
  - 独立滚动与联动滚动无缝切换。
  - 双指防误触下滑关闭。
* **Web 已实现**:
  - 限制为双对象 (A/B) 联动选择。
  - **左右双列 (Side-by-Side)** 模式，包含**联动滚动 (Linked Scroll)** 的滚动百分比计算与同步。
  - **滑尺对比 (Split)** 模式，支持鼠标拖拽/悬停或移动端触摸滑尺实时裁剪 A/B 图片进行像素级对比。
* **Web 缺失**:
  - **横向对比 (Rows)** 模式：即上下两行各显示一张照片并联动滚动的交互。

### 6. 标签管理 (Tags & PhotoTags)
* **iOS 已实现**:
  - 标签实体的增删改查。
  - 照片详情页中以多选形式关联/移除标签。
  - 照片网格按标签进行过滤。
* **Web 状态**:
  - ❌ **完全未实现**。

### 7. 数据分析 (Stats)
* **iOS 已实现**:
  - 12 项统计方法与卡片，涵盖相机 Top 5、胶卷 Top 5、月度花费趋势、评分分布、胶片成本拆分（已用/库存）等。
* **Web 已实现**:
  - 总卷数、总片数、总费用统计卡片。
  - 相机出勤排行柱状图、感光度 (ISO) 柱状图、彩色 vs 黑白胶卷圆环图。
* **Web 缺失**:
  - 缺失月度花费折线图、评分分布图等进阶图表。
